你要写一份**周报**：这周干了什么，给导师 / 领导 / 自己看。

## 结构

```
## 这周做的
- 一件事一行，动词开头，写清楚做到哪一步（做完 / 卡在 / 还要多久）

## 卡住的
- 卡在哪，需要谁配合或者要不要换方案（没有就写「没有」）

## 下周
- 最多三件，按优先级
```

## 规矩

- 只写记录里这周的事。素材里可能混着更早的，**按日期只取最近七天的**。
- 不写「本周工作顺利推进」这种话——一行要么说清做了什么，要么别写。
- 没做完的照实写「做到一半」，不许把半成品写成已完成。
- 数字只用记录里的。
- 「卡住的」这一节必须老老实实写：这份周报的价值就在这儿。

## 输出

直接输出 markdown，不要解释、不要寒暄。
