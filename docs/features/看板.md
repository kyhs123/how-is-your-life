# 看板（life board）

## 1. 这个功能对用户是什么

一条命令，生成一个网页文件，双击就能看自己记过什么：

- 按月排好的记录卡片，每张卡上有那句压缩过的话、证据档位、锚点、卡点、以及当时说的原话
- 上方两个小面板：证据档位分布（接触 / 复现 / 产出 / 能讲各几条）、情绪曲线（左旧右新，越高越好）

不需要装任何软件，不需要联网，不需要连数据库。文件就躺在 `vault/看板.html`，删了随时能重新生成。

```powershell
life board                # 生成 vault/看板.html
life board --open         # 生成后用浏览器打开
life board --include-private   # 连私密记录一起显示（别把这个文件发给别人）
```

## 2. 一次调用的完整路径

```
life board
  ↓
① 确保 vault 就绪（目录、占位文件）
② 遍历 vault/now/**/*.md，用 store.读条目() 逐条解析
     解析失败的文件跳过并报名字，不影响其它记录
③ 过滤：默认剔除 private: true 的记录（§8），并记住藏了几条
④ 算数字：条数、月份跨度、总分钟数、锚点个数、档位分布、情绪点序列、
         模型花费（从索引的 usage 表读，读不到就算 0）
⑤ 拼一个 HTML 字符串：头部摘要 + 两个面板 + 按月分组的卡片 + 页脚
⑥ 先写 .tmp 再改名（原子写入），落到 vault/看板.html
⑦ 打印摘要；--open 时调系统默认浏览器打开
```

```
vault/now/2026-11/*.md ──┐
                         ├─→ board.生成() ─→ vault/看板.html  （单文件，自带 CSS/SVG）
vault/index.sqlite ──────┘   （只读 usage 表算花费）
```

## 3. 关键代码在哪

```
life/board.py::生成()        读记录 → 过滤私密 → 拼页面 → 写文件
life/board.py::_算统计()     页面上那几个数字，全是数出来的，不猜
life/board.py::_情绪曲线()   把 valence 算成坐标，手写成 SVG 折线
life/board.py::_卡片()       一条记录一张卡
life/board.py::_样式()       全部 CSS 内联在这里（想改配色改这一段）
life/board.py::span()        转义：用户写的 < > & 不会把页面弄坏
life/cli.py::board()         命令本身：参数、打印摘要、--open
```

## 4. 为什么这么设计

最容易被做错的决定是：**要不要上一个前端框架 / 图表库 / 本地服务？**

看起来很自然——React + ECharts 十分钟就能画得比手写 SVG 漂亮。但它被否掉了，三个理由：

1. **CDN 外链 = 断网白屏。** 你的记录本来就是离线的，凭什么看它还得联网。
2. **框架 = 要装 Node、要打包。** 一个「人生记录命令行工具」会变成前端工程，你自己都跑不起来。
3. **起服务 = 端口、进程、防火墙。** 而且设计 §11 明写「不做服务端」。

所以选了最笨的办法：**Python 拼字符串 + SVG 手算坐标 + CSS 内联。** 代价是样式土一点、改起来慢；收益是这个文件三年后、换台电脑、网断着，双击还能打开。

第二个决定：**私密记录默认不显示。** 因为 html 一旦发出去就收不回来，而 `vault/` 是本地的、页面是可能被分享的。宁可少看一条，也不要手滑发出去。

第三个决定：**数据从 markdown 读，不从索引读。** 索引可能过期或被删，markdown 永远是真相源。

## 5. 已知限制

- **只能看，不能改、不能搜、不能按月份筛选。** 想改直接改 markdown 文件，再跑一次 `life board`。
- §4.8 里要求的「证据分布**变化**」「晋升事件」「下周一个建议」**没有**——前两样要等第 3 周的晋升功能，最后一样要等第 4 周的 AI 回顾。现在硬做只能是假数据。
- 情绪曲线至少要 2 条带情绪的记录才画得出来，否则显示一句提示。
- 记录到几千条时这个 html 会很大（每条约 1KB），没做分页或折叠。
- 深色/浅色跟随系统设置，没有手动切换按钮。
- 这个命令是第 1 周交付之后追加的（把 §4.8 的「单文件 HTML」提前做了展示部分），**`DESIGN.md` 正文还没有记这一笔**——等你确认要不要写进去。
