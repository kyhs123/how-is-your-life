# 启动：双击就能打开，不用碰命令行

## 1. 这个功能对用户是什么

仓库根目录有一个 **`启动.bat`**，双击它：

1. 一个黑窗口出现，打印两行话（网页界面已启动、地址是什么）；
2. 浏览器自己弹出来，直接就是首页。

**关掉那个黑窗口 = 退出。** 没有托盘图标、没有开机自启、没有后台进程留在你看不见的地方。

已经开着的时候再双击一次，**不会报错**，只会把浏览器再叫出来一次，然后告诉你「已经开着了」。所以你不用记得自己开没开——双击总是对的。

## 2. 一次双击的完整路径

```
双击 启动.bat
  ↓
chcp 65001          ← 让黑窗口认得中文（否则打印出来是乱码）
cd /d "%~dp0"       ← 切到这个 bat 所在的文件夹（不管从哪里双击都对）
  ↓
.venv\Scripts\life.exe server --open
  ↓
life/cli.py::server()
  ↓
life/server.py::启动(8770, 打开浏览器=True)
  ├─ 已经在运行(8770)？
  │    ├─ 是 → 打印「已经开着了」+ 打开浏览器 + 直接返回（不抢端口）
  │    └─ 否 ↓
  ├─ 造服务器(8770)         ← 只绑 127.0.0.1，外面的机器连不上
  ├─ webbrowser.open(地址)  ← 浏览器弹出来
  └─ serve_forever()        ← 就停在这里，直到你关掉窗口
```

`.venv\Scripts\life.exe` 找不到的时候（比如换了台电脑还没装环境），bat 会停下来告诉你「先照 README 的安装做一遍」，而不是闪一下就消失。

## 3. 关键代码在哪

```
启动.bat                              双击入口。只有十几行，全是路径和判断
life/server.py::已经在运行(端口)        去要一次首页，看回来的是不是我们的页面
life/server.py::启动()                先问「开着了没」，再决定是开新的还是叫浏览器
life/server.py::本机服务器             allow_reuse_address 在 Windows 上关掉（见 §4）
life/cli.py::server                   --port / --open 两个参数
```

## 4. 为什么这么设计

**① 为什么不做一个桌面快捷方式（.lnk）放在桌面上？**

那确实更近一步，但它要往仓库外面写文件（桌面在你的用户目录里），而 `AGENTS.md` 第一条硬约束是「所有文件都放在本仓库内」。所以这次只做了仓库里的 `启动.bat`。

想要桌面图标，你不用我帮忙也可以：右键 `启动.bat` → 发送到 → 桌面快捷方式。**这是你自己的电脑，你想放哪都行**，只是这个仓库不替你做主。

**② 为什么不做「后台常驻 + 开机自启」？**

听起来更省事，但用户会失去「它现在开着吗」这个感觉：某天它莫名其妙占着 8770，你想不出是谁；或者它开机就崩，你却看不到任何报错。**能看见的窗口 > 看不见的进程**，尤其是当你开始往里面写真实人生记录之后。

**③ 为什么端口冲突不自动换一个？**

自动找空闲端口写起来只要三行，但那样地址会变，浏览器书签和「我记的那个 8770」全部失效。所以端口写死，**冲突时如实报错**并告诉你换端口的命令。

**④ 为什么「已经开着了」要真去请求一次首页？**

判断「端口被占」很容易（`bind` 失败就知道），但那只说明**有东西在占**，不说明是**我们**。如果不问清楚就直接用，会出现「双击了，浏览器打开的是一个完全无关的页面」。所以这里真发一次 HTTP 请求，看页面标题里有没有「你过得怎么样」——有才是我们自己。

**⑤ 顺带修掉的一个 Windows 坑**

Python 的 `HTTPServer` 默认 `allow_reuse_address = 1`（打开 `SO_REUSEADDR`）。这个开关在 Linux 上只是「重启后能立刻复用端口」，很温和；但在 Windows 上它的语义是「**可以抢别人已经占着的端口**」——抢到之后对方的服务就收不到连接了。

所以 `本机服务器` 在 Windows 上把它关掉：端口真被占了就 `OSError`，我们如实报「用不了」，而不是把别人的程序弄瘫。

## 5. 已知限制

- **只有 Windows 能用这个 bat。** macOS / Linux 还得敲 `.venv/bin/life server --open`。
- **窗口不能最小化到托盘**。关掉就是停，这一点是故意的（见 §4②）。
- **按 Ctrl+C 会多问一句 `Terminate batch job (Y/N)?`**：那是 Windows 在问「要不要连 .bat 这层壳一起终止」（真正干活的是里面的 `life.exe`）。**打 `Y` 回车就是退出**，打 `N` 是继续跑。嫌它烦就点窗口右上角的 × ——那条路不会弹这句。
- **端口写死 8770**，不给自动挑。真被别的程序长期占着，用 `life server --port 8771` 临时换。
- **模型接口没起也能打开网页**，只是「记一条」会等很久然后失败、`ask` 会如实报错。打开这件事不依赖网络。
- 黑窗口里的中文依赖 `chcp 65001`（文件本身是 UTF-8 无 BOM、CRLF 换行）。如果哪天你用什么工具改过这个文件又存成了 GBK，那几行提示会变乱码——程序本身不受影响。
