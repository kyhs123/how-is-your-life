# 画像（life portrait）

## 1. 这个功能对用户是什么

每季度一次，它翻一遍你这半年写的东西，然后写几条**关于你的假设**——不是判决。

> ### 我现在的假设
> ——
> - 我猜你在被否定时会先缩起来，而不是争辩——被说「命名像机器翻译」那天，你写的是「很受打击」，第二天就全改了。（依据：3 次类似场景）
> - 我猜你不是拖延，是「对别人安排的事没动力」。自己选的毕设方向你连着做了三周，被派的调研拖了两周。（依据：4 次类似场景）
>
> ### 相对上季度的变化
> ——
> - ~~拖延型~~ → 不是拖延，是「对别人安排的事没动力」。

```powershell
life portrait          # 生成/更新本季度画像
life portrait --diff   # 只看和上季度的变化
```

## 2. 一次调用的完整路径

```
life portrait
  ↓
① 数材料：全部非私密记录、底色（core.md）、活跃章节、情绪统计（正负条数、触发词、按月平均）
② 读上季度画像全文（没有就说「这是第一份」）
③ 把这些交给模型，system = life/prompts/portrait.md（要求：写假设、每条带依据、旧假设用删除线留着）
④ 把模型写的正文原样存成 vault/portrait/2026-Q4.md
⑤ 检查「每条假设有没有写依据」，没写的照实点出来
  ↓
life portrait --diff
  ↓
⑥ 从当前季度的文件里只抽出「相对上季度的变化」那一块
```

## 3. 关键代码在哪

```
life/portrait.py::生成()        数材料 → 调模型 → 写文件
life/portrait.py::情绪统计()    正负条数、触发词、按月平均（全是数出来的）
life/portrait.py::_材料()       拼给模型看的那几块
life/portrait.py::缺依据的假设() §4.7 的验收：假设必须带「依据：N 次」
life/portrait.py::只看变化()    --diff 的实现
life/prompts/portrait.md        写假设的规矩
life/cli.py::portrait           命令本身
```

## 4. 为什么这么设计

**① 为什么写假设，不写结论？**
设计里给了理由，我照做了：固定标签必然滑向**巴纳姆效应**（「你有时外向有时内向」这种话谁都觉得准）。而且「父母会记错你的事，能承认自己记错，比全知更像真的」——一个会说「我上次猜错了」的系统，比一个永远正确的系统更可信。

**② 为什么旧假设要用删除线留着，不直接覆盖？**
因为「我上次猜错了」本身就是信息。直接覆盖等于假装自己一直都对，也让你看不出自己的变化轨迹。

**③ 为什么「没写依据的假设」要单独点出来？**
模型很容易写「你是一个很努力的人」这种场面话——听着舒服，但推不出任何行动。所以代码会检查每条假设里有没有「依据」，没有就单独列出来提醒你：**这些不是数据推出来的，信之前先怀疑一下。**

## 5. 已知限制

- **季度是自然季度**（1~3 月 / 4~6 月 / 7~9 月 / 10~12 月），不是「最近 90 天」。
- 材料里没有「情感记录的原文」（只有统计），所以画像看得见模式、看不见具体情绪场景。
- 假设的质量取决于模型。**实测会遇到思考型模型把 token 花光、正文为空的情况**——现在会报错并提示调大 `max_tokens`，不会留下空白文件。
- 季度切换时不会自动跑，得你自己记得。
- 底色（core.md）章节→底色没实现，现在底色只能手写，画像只能读它。
